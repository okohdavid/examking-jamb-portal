# Exam King - JAMB Portal Clone

A fully responsive, interactive clone of the JAMB portal web application. This project simulates the user experience of checking exam updates and generating result slips.

## 🚀 Features
* **Interactive Result Page:** Users can simulate checking their examination results.
* **Responsive Design:** Optimized for both mobile devices and desktop screens.
* **Clean Code Architecture:** Built from scratch using modern web standards.

## 🛠️ Technologies Used
* **HTML5:** For page structure and semantic markup.
* **CSS3:** For custom styling, layout, and responsive media queries.
* **JavaScript:** For dynamic result generation and portal logic.
